## Cara Menggunakan

### Google Colab

1. Buka [Google Colab](https://colab.research.google.com/).
2. Pilih **File → Open notebook**.
3. Buka tab **GitHub** dan masukkan URL repositori, atau unduh file `.ipynb` lalu pilih **File → Upload notebook**.
4. Jalankan sel secara berurutan dari atas ke bawah.
5. Baca penjelasan, kode, visualisasi, dan hasil pada setiap bagian.

### Menjalankan secara lokal

1. Pastikan Python dan Jupyter Notebook/JupyterLab sudah terpasang.
2. Clone repositori:

   ```bash
   git clone <URL-REPOSITORY>
   cd <NAMA-FOLDER-REPOSITORY>
   ```

3. (Opsional) Buat dan aktifkan virtual environment:

   ```bash
   python -m venv .venv
   ```

   **Windows**
   ```bash
   .venv\Scripts\activate
   ```

   **Linux/macOS**
   ```bash
   source .venv/bin/activate
   ```

4. Instal Jupyter bila belum tersedia:

   ```bash
   pip install jupyter
   ```

5. Jalankan:

   ```bash
   jupyter notebook
   ```

6. Buka notebook yang ingin dipelajari dan jalankan sel secara berurutan.
